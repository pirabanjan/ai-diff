## Principles used across all guides

- Git is the source of truth for code.
- AIDIFF keeps local evidence and session history.
- AI-generated summaries are interpretation, not ground truth.
- Validate with actual repo state and command output before claiming completion.
- Keep metadata local-first and private unless the user asks otherwise.
