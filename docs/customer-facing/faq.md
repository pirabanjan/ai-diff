# AIDIFF FAQ

## What is AIDIFF?

AIDIFF is a local-first traceability layer for AI-assisted software work. It records the connection between code changes, AI session activity, validation evidence, and feature intent.

## Do I need to use a cloud service?

No. AIDIFF is designed to work locally by default.

## Is Git still the source of truth?

Yes. Git remains the authoritative code history.

## Can I use this with different AI tools?

Yes. AIDIFF is designed to be vendor-neutral and work across multiple AI platforms.

## Does it replace code review?

No. It supports review by preserving evidence and context, but the human review process remains essential.

## Is it suitable for customer environments?

Yes. It is designed for internal and customer-facing deployment in local-first environments.
